# Skill: Follow-up email (UK)

## When to use
User wants an external-facing **follow-up email** drafted from a ContextDay meeting — polite, concise, UK English.

## Data
- Single nominated meeting window from ContextDay transcript/context
- Recipients / subject only if stated by the user or clearly evidenced; otherwise placeholders

## Hard rules (always)
- Only write verifiable content from the provided ContextDay transcript/context
- Ambiguous commitments marked **TBC**
- No tax/legal conclusions
- External-facing UK English

## Output structure
Produce a draft email body (and optional subject line):
1. Short thanks / context line
2. Decisions confirmed (bullet)
3. Actions with owners and dates (or TBC)
4. One clear ask / next step if evidenced
5. Polite close

## Channel
**Prefer Gmail draft** (or Docs/Word/local md·txt·docx if the user chooses).  
**Never auto-send** email — create a draft / local file only until the user sends manually.

## Example / Preview
```text
Subject: Follow-up — Q3 roadmap sync (14 Oct)

Hi both,

Thanks for joining today’s roadmap sync. Please find a short recap below.

Decisions
• Pilot beta targeted for 28 Oct

Actions
• Sam — circulate the beta invite list by Fri 17 Oct
• Priya — confirm staging capacity — TBC

Happy to adjust if I’ve missed anything.

Best regards,
[Your name]
```
