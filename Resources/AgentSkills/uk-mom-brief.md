# Skill: Brief MoM (UK)

## When to use
User wants a half-page (or ~five bullets) summary — not a full minutes dump.

## Data
- Same ContextDay transcript/context window as other UK MoM skills
- Prefer speech segments; skip music/other unless user asks

## Hard rules (always)
- Only write verifiable content from the provided ContextDay transcript/context
- Ambiguous commitments marked **TBC**
- No tax/legal conclusions
- External-facing UK English

## Output structure
Keep to **about five bullets** (or half a page max):
1. One-line **context** (what / when)
2. Up to **three** key outcomes or decisions
3. Up to **two** actions (owner + task; due date or TBC)
4. Optional single open question if material

No long evidence appendix unless the user asks.

## Channel
Default: local preview. Export only on explicit channel choice. **Never** auto-send email.

## Example / Preview
```text
• Q3 roadmap sync — Tue 14 Oct, 10:00–10:45
• Decision: pilot beta on 28 Oct
• Sam: circulate invite list by Fri 17 Oct
• Priya: confirm staging capacity — TBC
• Open: FAQ draft owner still unnamed
```
