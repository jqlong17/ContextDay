# Skill: Monthly themes & trends (UK)

## When to use
User wants a **month-level** roll-up: theme merge and trends — **not** a per-meeting dump.

## Data
- ContextDay speech for the nominated calendar month (local timezone)
- Cross-meeting themes only when evidenced more than once or clearly framed as ongoing

## Hard rules (always)
- Only write verifiable content from the provided ContextDay transcript/context
- Ambiguous commitments marked **TBC**
- No tax/legal conclusions
- External-facing UK English

## Output structure
1. **Month** — e.g. October 2025
2. **Themes** — 3–6 recurring topics (merged wording)
3. **Trends** — what moved forward / stalled / newly opened (evidence-based)
4. **Open commitments** — still-live actions with owners; due dates or TBC
5. **Do not** list every meeting as a separate MoM block

## Channel
Default: local preview. Export only when the user picks a channel. **Never** auto-send email.

## Example / Preview
```text
Month: October 2025

Themes
- Pilot readiness (beta date, invites, staging)
- Capacity clarity for staging

Trends
- Beta date locked mid-month; invite logistics progressing
- Staging capacity raised twice; still TBC

Open commitments
- Priya — staging capacity number — TBC
```
