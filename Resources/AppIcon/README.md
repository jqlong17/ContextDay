# AppIcon source

`icon-1024.png` must be an **opaque** dark-charcoal square with the twin-eye orb centered.

- Desktop floating control uses transparent `Resources/DesktopOrb/idle.png` instead.
- Regenerate catalog sizes: `python3 scripts/generate_appicon.py`
- Parent may later supply a hand-finished opaque `AppIcon-1024.png` — drop it in as `icon-1024.png` and regenerate.
