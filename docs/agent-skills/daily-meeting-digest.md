# Skill: 每日会议摘要（ContextDay）

按**本地自然日**汇总 ContextDay 时间线中的会议/讨论片段，输出一日 digest。

## 输入

- 日期：本地日历日（如 `2026-10-28`），缺省=今天。
- 可选：仅 `mic`、或含 `system`；关键词过滤。

## 步骤

1. `GET http://127.0.0.1:18787/health` → 确认 `"service":"ContextDay"`。
2. 将自然日转为 `[t0_ms, t1_ms]`（该日 00:00:00–23:59:59.999，用户本机时区）。
3. `POST /v1/tools/get_window` 取窗内段；可用 `list_activity` 看小时桶密度。
4. 按「场次」粗分：相邻 gap 较大（例如 >15–30 分钟）或主题明显切换时切开；不要把全日粘成一场。
5. 输出结构：
   - 当日概览（场次数、总时长粗估）
   - 每场：标题候选、时段、3–7 条要点、待办
   - 「未归类碎片」：短促、无法成会的段
6. 需要单场深挖时，转交 [meeting-minutes.md](./meeting-minutes.md)。

## 禁止

- 虚构未出现在 Segment.text 中的议程
- 将 digest 默认上传云端；仅在用户明确要求时走飞书投递技能
