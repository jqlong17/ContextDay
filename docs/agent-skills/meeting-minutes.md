# Skill：从 ContextDay 整理会议纪要

## 何时用
用户说「整理刚才/今天某场会议」「出纪要」「会后总结」时。

## 数据
- 只读打开 `{RECORDS_ROOT}/db/contextday.sqlite`
- 按 `t0_ms`–`t1_ms` 与关键词（议程名、参会人称呼）圈选 `gate_label=speech` 的 `text`
- 需要时用 `audio_path` 回听核对；不要假设每日 txt

## 输出结构（中文中档）
1. **会议标题**（自拟或用户给定）  
2. **时间范围**（本地时区）  
3. **决议 / 结论**  
4. **待办**：负责人 + 事项 + 可选截止日期  
5. **风险 / 未决**  
6. **原文摘录**（短、可核对）

## 规则
- 不编造未出现的承诺；听不清标「[听不清]」
- 脱敏：对外发出前去掉私人电话/住址；客户名按用户当场指示保留或化名
- 默认只给用户预览；未经明确「写飞书/发出」不要调用外部写入
